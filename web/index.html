From demo to live

Set APP_MODE=live and add an OpenAI API key to generate scripts, images and English narration. Add a YouTube API key for discovery and run scripts/connect_youtube.py for upload authorization.

TikTok supports manual export or Buffer automatic publishing. Configure Buffer and Cloudinary credentials; approved videos are uploaded to public media hosting. Select Public when queuing a Buffer post. Direct Post is not implemented for this internal tool.

Keep this app on localhost. ChatGPT Plus does not cover provider API usage. Follow docs/API_SETUP_VI.md for step-by-step credential setup.
